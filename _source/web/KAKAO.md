# 카카오맵 버전

로컬 진입점: `http://127.0.0.1:4173/` (`kakao.html`도 동일한 카카오 화면 유지)

공개 진입점: https://minjaekim0.github.io/dent-geography/
기존 자체 SVG 지도는 `legacy/index.html`로 보관하고 웹에서는 제공하지 않는다.
공개 화면의 지하철 노선 체크박스·별도 강조선 로딩은 제거했다. 카카오 기본 지도 자체의 지하철 표시는 그대로다.

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory web/dist
```

## 유지되는 분석 기능

- 시군구 252개 / 읍면동 3,558개 전환, 지역 클릭·선택 해제, 상세정보와 과목별 펼침 목록
- 치과기관 현황 2023–2026년, 연도 차트 클릭·드래그, 이전/다음
- 치과기관·치과의사·전문과목별 전문의, 전체 자격 합계·통합치의학과 제외 합계
- 실제 수 / 인구 1만 명당, 주민등록 / 2020년 주간인구(시군구), 같은 결측값·분모·반올림 규칙
- 2000–2025년 개원 / 폐업 / 순증감, 단일 연도·직접 기간·3/5/10년 이동 창·전체 기간
- 기간 차트 클릭·드래그·Esc 취소, 순위·총계·범례·출처·데이터 다운로드
- 지하철 강조선 전환, 확대/축소/초기화, 지도별 시점 및 선택 지역 유지

추가: 카카오 장소/주소 검색, 검색 위치 마커, 일반 지도/스카이뷰, 통계 색상 투명도,
키보드로 선택 가능한 전체 분석 지역 목록. 새 지도 API 연결만 변경하고 기존 데이터의 기관명 제외 기준,
과거 기록 전수성, 위치 미배정 및 경계 기준 시점은 바꾸지 않는다.

## 지도와 데이터 출처

| 항목 | 사용 방식 |
| --- | --- |
| 배경, 도로, 지명, 확대/이동, 위성영상 | Kakao Maps Web SDK |
| 장소·역·주소 검색 및 좌표 | Kakao services.Places / Geocoder (사용자 검색 시에만 호출) |
| 경계 좌표의 화면 투영, 면/선 렌더링, 선택 이벤트 | Kakao Polygon / Polyline / MapProjection |
| 분석용 행정구역 경계 | 기존 `district-boundaries.json`, `eupmyeondong-boundaries.json`의 모든 원본 좌표 |
| 지하철 노선 강조선 | 기존 `transport-network.json`의 MOIS_KR_Subway 자료; 카카오 Polyline으로 표시 |
| 인구·치과기관·인력·전문과목·개폐업 | 기존 심평원·행안부·통계청 집계 JSON |

카카오의 공개 [Web API](https://apis.map.kakao.com/web/documentation/)와
[REST API](https://developers.kakao.com/docs/ko/kakaomap/rest-api)에는 전국 분석용 행정구역 폴리곤과
별도 지하철 노선 레이어를 가져오는 기능이 문서화되어 있지 않다. 카카오의
좌표→행정구역 API는 행정구역 명칭/코드 조회이며 경계 좌표의 대체재가 아니다.
카카오 장소 검색 결과도 기존 기관·인력·과거 개폐업 통계의 대체재가 아니다.

이 때문에 지원되지 않는 경계·강조선·통계 원자료만 기존 자료를 유지한다.
카카오의 비공개 타일 주소나 내부 API는 사용하지 않는다. 새 페이지에는 기존 SVG 생성,
자체 지도 투영, 자체 지도 드래그/줌 코드가 없다. SDK가 내부적으로 만드는 SVG는 카카오가 관리한다.
카카오 지도는 최신 지명/도로를 보여주므로 분석 경계의 시점과 다를 수 있다.
줌 단계와 애니메이션은 카카오 SDK 기준이며, 원래 화면과 픽셀 단위로 같다는 의미는 아니다.

## 파일과 재생성

- `legacy/index.html`: 기존 UI·계산식과 SVG 렌더러의 보관본. 공개 디렉터리 밖에서 유지한다.
- `scripts/build-kakao.mjs`: 기준 페이지에서 UI와 계산식을 복사하되 기존 렌더러를 제거하고 카카오 렌더러에 연결한다.
- `dist/index.html`, `dist/kakao.html`, `dist/kakao-core.js`: 생성된 카카오 전용 파일. 분석 UI를 변경하면 재생성한다.
- `dist/kakao-map.js`: 카카오 SDK 초기화, 도형 캐시·뷰포트 표시·선택·검색.
- `dist/kakao.css`: 카카오 전용 배치/반응형 스타일. 기존 SVG용 전역 스타일은 SDK에 적용되지 않도록 제거한다.

```sh
node web/scripts/build-kakao.mjs
node web/scripts/build-kakao.mjs --check
node --test web/tests/kakao-parity.test.mjs
```

지도별 SDK 인스턴스를 유지하고 화면과 교차하는 폴리곤만 표시한다. 지표 변경 시 같은 폴리곤의 색상을 갱신한다.
도형 생성은 프레임별로 나누고 새 요청 시 이전 작업을 취소한다. 통계/순위/범례는 뷰포트와 관계없이
전국 원자료 전체로 계산한다. 섬·구멍을 없애거나 경계를 단순화하지 않는다.

JavaScript 키는 브라우저용 공개 키이며 SDK 로딩에만 사용한다. 허용 도메인에는
`http://127.0.0.1:4173`, `http://localhost:4173`, `https://minjaekim0.github.io`를 등록한다.
HTML/JS/데이터 경로는 상대 경로라 GitHub Pages 프로젝트 경로에서도 사용할 수 있다.
GitHub Pages 공개 배포는 `scripts/prepare-github-release.mjs`로 별도 배포 저장소에 준비한다.
Sites의 기존 설정과 접근 권한은 변경하지 않는다.

  실제 휴대폰 하드웨어 성능/멀티터치 테스트를 대신하는 것은 아니다.

이 검증은 기존 기능·수치의 동등성을 확인하며 데이터 원천의 정확성 자체나 모든 기기의 성능을 보증하지 않는다.

## 개별 치과 위치 표시 (2026-11-03)

지도 도구의 `치과 위치 표시`를 기본으로 켠다. 축소 시 공간별 치과 수를 먼저 묶고(화면 최대 240개 표시),
확대 시 화면 안의 치과를 개별 마커로 표시한다. 파랑은 카카오 연결 위치 17,771곳,
주황은 심평원 미검증 위치 1,852곳이며, 유효 좌표 없는 1곳은 표시하지 않는다.
클릭하면 기관명·주소·위치 출처·조회일·카카오 장소 링크를 확인할 수 있다.

기관 목록은 2026-06-30 현황, 카카오 조회는 2026-11-03이다. 위치 레이어에는 대학·부속 등
분기 현황 전체가 포함되며, 기존 개원가 통계의 집계 범위와 다르다. 연도별 집계나 과거 개폐업 위치로 소급하지 않는다.

`python3 scripts/build_clinic_locations.py`로 내부 대조 결과에서 공개 필드만 추출한다.
기관 식별자는 해시로 대체하며 원본 요양기호와 REST API 키는 공개 데이터에 넣지 않는다.
`clinic-model.mjs`는 화면 범위/출처 필터와 카카오 링크 검사를, `kakao-clinics.js`는 클러스터·마커·정보창을 담당한다.

검증: 웹 테스트 38개 통과. 실제 브라우저에서 전국 19,621곳 표시, 강남구 확대 후 개별 마커,
정보창 유지, 심평원 위치 필터를 확인했다. 위치 자료는 건물 실측 검증과 구분한다.

주소 우선 판정 v3: 같은 시군구에서 이름(치과/치과의원 표기 통일)이 일치하는 고유 후보는
도로명·건물 주소가 달라도 카카오 주소와 좌표를 함께 우선한다. 원본 심평원 주소와 연결 근거는
내부 검토 자료에 남긴다. 정보창에는 카카오 주소 적용 및 주소 차이를 표시한다.
서울백운호수치과의원은 경기 의왕시 백운중앙로3길 7로 연결된다.

v4는 지역명 순서와 지점명 표기를 대조한다. 예를 들어 유디여수치과의원은 유디치과의원 여수점으로 연결된다.
인천 옛 서구 주소는 서해구·검단구의 새 주소와 대응하며, 통계의 분구 전 경계는 그대로 보존하고 화면에 이를 안내한다.
`web/scripts/incheon_split.py`는 서해구 15개 동의 같은 경계·이름을 검증하여 코드 연결을 추가하며,
경계가 달라진 검암경서동은 별도로 보류한다. 분할된 두 구를 한 지역의 코드로 합치지 않는다.

v5는 SM/에스엠 같은 발음 표기, 영문·한글 중복 병기와 인천 동구·중구 개편도 반영한다.
이름·주소가 명확한 일반 의료분류나 검색 제한 사례는 그 이유만으로 보류하지 않는다.
파랑 17,771곳, 주황 1,852곳, 좌표 없음 1곳이며, 원본 데이터와 통계의 시점·범위는 보존한다.


## 치과 표시 성능 개선 (2026-11-03)

- 처음에는 `current-clinics-index.json`(1,756,427 bytes)의 이름·좌표·출처만 읽고 공간 색인을 만든다.
  기존 전체 파일(7,978,426 bytes)은 호환용으로 유지한다. 최초 치과 자료 크기는 약 78% 줄었다.
- 주소·카카오 링크는 치과를 클릭할 때 500곳 단위 상세 파일로 불러온다. 상세 파일 캐시는 최대 6개다.
- 전국 화면에서는 개별 마커 19,623개를 생성하지 않고 묶음 숫자만 표시한다. 줌과 화면 크기에 맞춰
  최대 240개 표시를 생성하며, 확대하면 원래 좌표의 개별 마커가 나타난다. 묶음의 기관 수는 정확히 합산한다.
- 같은 좌표의 기관은 목록에서 선택할 수 있고, 큰 목록은 50개씩 나눈다. 지도 이동 때 기존 표시를 재사용하며
  사라진 표시만 분리한다. 출처 필터와 카카오 주소·좌표 우선순위는 동일하다.
- 행정구역 폴리곤의 스타일이 같으면 SDK에 재설정을 요청하지 않는다. 경계 좌표·통계 값은 단순화하지 않는다.

로컬 같은 브라우저의 전국 화면 1회씩 측정한 치과 표시 처리 시간은 1,521.2ms → 8.5ms,
생성된 지도 표시 수는 19,623개 → 9개였다. 이는 치과 레이어의 동기 처리 시간이며 전체 로딩 시간이나
모든 기기의 FPS 측정이 아니다. 전체 19,623곳(카카오 17,771 / 심평원 1,852)은 동일하게 집계됐다.
공간 색인 대조, 전체 기관·좌표·상세 정보 무손실, 표시 수 상한, 객체 재사용·필터·끄기,
폴리곤 스타일 재사용을 자동 검증한다. 실제 브라우저에서 묶음 확대, 주소 검색, 개별 치과 상세 주소,
출처 필터와 표시 끄기·켜기를 확인했다.

## 지도 중심 화면 개편 (2026-11-06)

상위 탐색을 치과 현황 / 개원·폐업 / 인구 분석으로 나누고 각 영역의 마지막 지표를 유지한다.
`dist/workspace.js`가 기존 분석 엔진과 인구 iframe 사이의 탐색 상태만 조정하며 계산·데이터는 바꾸지 않는다.
`build-kakao.mjs`는 `scripts/redesign-page.mjs`로 공개 페이지의 배치를 구성한다.
기관 연도별 추이와 지역 순위는 접이식이며, 색상 진하기·치과 위치·좌표 출처는 지도 설정에 둔다.
개별 치과 위치는 기본으로 켜며, 지도 도구의 체크박스로 켜고 끈다. 지역별 통계 색칠은 아래 실험실에서만 선택한다. 색칠을 꺼도 경계 선택과 지역 수치는 유지하고 범례만 숨기며, 진하기 설정은 다시 켤 때 보존한다. 출처별 범례·조회일·범위 안내는 유지한다.

## 통계 색칠 실험실 (2026-11-06)

- 기본 홈 `index.html`과 호환 진입점 `kakao.html`에서는 지역별 치과 통계 색칠·통계 색상 진하기 조절을 제공하지 않는다. 홈의 `data-stat-fill="off"` 설정으로 체크박스가 없어도 색칠과 치과 통계 색상 범례를 끈다.

- 홈의 지역 정보·요약·순위 사이드 패널과 시군구/읍면동 전환도 표시하지 않는다. 상단 제목과 지도 도구 아래는 지도가 남은 화면 전체를 채운다. 고정 비율로 제한하지 않으며 창 크기와 도구 줄 높이에 맞춰 조정한다. 데이터 안내·집계 기준 및 출처는 지도 설정 안으로 옮겨 접근성을 유지한다. 실험실의 기존 패널과 전환은 보존한다.
- 홈 제목 옆 **실험실** 링크로 `lab.html`에 들어가면 기존 **지역별 통계 색칠** 체크박스와 지도 설정의 **통계 색상** 조절기를 사용할 수 있다. 실험실도 처음에는 색칠을 끄고, **기본 홈으로** 링크로 돌아오면 홈에서는 계속 꺼진다.
