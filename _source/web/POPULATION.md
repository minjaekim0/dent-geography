# 읍면동 인구 지도

## 2026-09-21 행정구역 변경 연결

이 절은 아래 초기 구현 설명의 ‘동일 코드만 연결’ 방식을 대체한다.
`admin-history-model.mjs`와 `data/admin-history.json`이 공식 변경표에서 확인한
1,022개 행정기관 구·신 코드와 여주·당진의 시군구 명칭을 연결한다.
강원·전북 특별자치도, 남구→미추홀구, 군위군 편입·삼국유사면,
2026 화성시 일반구 설치, 전남광주 통합 하위 지역, 인천 신설구 하위 행정동,
안양 명칭 변경을 포함한다. 원본 73,087행의 수치·명칭·코드는 바꾸지 않는다.

- 주민등록인구: 지도, 검색, 선택, 연령·성별 증감, lazy 시계열, JSON 모두 같은 연결 사용.
- 시도 필터는 **각 원자료 시점의 소속** 유지. 구·신 시도 합계나 분할된 구는 임의 합산하지 않는다.
- 군위 편입 전후 대구·경북 합계, 검단 분리 전후 인천 서구 합계의 증감은 비교 불가.
- 주간인구: 미추홀·군위·여주·당진 및 도 명칭 연결. 같은 이름이나 코드가 달라진
  창원·청주 등은 단순 명칭 변경으로 인정하지 않고 비교/차트 연결을 중단한다.
- 원자료 관측값은 표에 유지. 지도 명칭을 연결한 뒤 최신 보유 KOSIS 조사(2020)와 같은
  KOSIS 코드 또는 검증한 명칭 변경인 관측값만 도형 연결. 경계코드와 KOSIS 코드는 별개 체계다.
- 분할·통합·동일 코드 경계 변경의 **전국 완전 보정은 아니다**. 모르는 변경을 추정하지 않는다.
- 치과 원통계·경계 좌표·기존 보관 코드는 변경하지 않는다.
- 메인 치과 지도의 지역 선택·툴팁·선택 상세에는 검증된 현 명칭과 원자료 명칭을 함께 표시한다.
  치과 순위표의 당시 명칭과 집계 기준은 원자료 그대로이며 행정구역을 새로 합산한 통계가 아니다.

변경표, 시행일, 공식 출처는 `admin-history.html`에서 검색 가능하다.
공식 MOIS 엑셀의 **행정동 열**을 읽으며 법정동 코드를 섞지 않는다.
원표 해시·시트·행번호를 registry에 보존하고, `build-admin-history.py`로 재생성한다.
스프레드시트의 셀 스타일 오류는 read-only 값 추출로 우회하며 원본을 수정하지 않는다.
입력은 `/tmp/admin-{gangwon,jeonbuk,hwaseong,jeonnam,incheon}.xlsx`.

지도 연결(3,558개 보유 도형 기준): 2026-08 3,115→3,541, 2025-12 3,525→3,554,
2008-12 2,643→3,104. 나머지 미연결 관측값은 표·시계열로 제공한다.
시계열은 관련 구·신 코드 파일만 지연 로딩하며 캐시는 6개 그룹으로 제한한다.

로컬: http://127.0.0.1:4173/population.html

카카오 지도에서는 **치과 현황 → 지도 지표 → 인구 분포**로 연다.
페이지 이동 없이 연령·성별·연도 필터와 인구 지도가 표시된다. 다른 지표로 전환했다가
돌아와도 인구 선택 조건을 유지하며, 인구 화면을 벗어나면 연도 재생을 정지한다.
치과 전용 분모·시군구 전환·지하철 도구는 인구 지표에서 숨기고 복귀 시 복원한다.
독립 `population.html` 주소와 기존 지도 제목의 인구 지도 링크도 계속 사용할 수 있다.
기존 읍면동 인구 분포는 주민등록인구를 사용한다. SGIS 자료는 별도의 `100m 인구 히트맵` 지표로 제공한다.

통합 패널은 동일 출처의 지연 로딩 iframe으로 기존 두 분석 코드의 전역 변수 충돌을 막는다.
내부 제목은 숨기고 높이는 콘텐츠에 맞춰 동기화한다. 메시지는 origin과 source를 모두 검사한다.
생성기 `build-kakao.mjs`와 `kakao-population-panel.js`가 메뉴/복귀 처리를 담당한다.

## 제공 기능

- 전국 읍면동 인구, 시도 범위, 지역명/코드 검색, 지도 클릭/목록 선택.
- 2008–2025년 각 12월 말 + 2026년 8월, 총 19개 시점. 최신 월은 연말과 구분.
- 전체/남자/여자, 10세 연령대·65세 이상·유소년/생산연령 프리셋, 1세 단위 직접 범위.
- 인구수, 전체 주민 대비 선택 인구 비중, 보유 경계 면적 기준 참고 밀도.
- 전국·시도·선택 읍면동의 연도별 인구수 차트/표, 점 선택, 이전/다음·슬라이더·재생.
- 연도 공통 색상 구간, 미연결 지역도 포함한 목록, 조건·출처 포함 JSON 내보내기.
- 기존 Kakao SDK 지도·검색·스카이뷰·확대/이동·투명도 도구 재사용.

## 원자료 및 계산

행정안전부 [행정동별 연령별 인구현황](https://jumin.mois.go.kr/ageStatMonth.do)
화면의 공식 CSV 다운로드 양식을 이용한다. 월간, 등록구분 전체, 1세 단위 0–100세 이상,
남녀 포함, 전체 읍면동 현황 및 전국/시도 현황을 각각 다운로드한다. 키/로그인 불필요.

- `../data/incoming/population/age/YYYY-MM.csv`: 원본 CP949 CSV. 수정하지 않는다.
- `YYYY-MM-national.csv`: 전국/시도 대조용 별도 다운로드.
- `dist/data/population/manifest.json`: 원본 SHA-256, 시점, 공식 전국값, 지역 연결률, 원자료 합계 차이, 경계 해시.
- `YYYY-MM.json`: 원자료 전체 지역 행. 통계코드 변경/명칭 변경을 억지로 합치지 않는다.
- `series-*.json`: 시도 합계 또는 시군구 코드 접두사별 과거 자료. 선택 시에만 로드.

인구수는 해당 성별의 선택 연령 **양 끝 포함 합계**다. 100은 ‘100세 이상’ 열린 구간이다.
비중의 분모는 동일 시점·동일 지역의 남녀 전체·전 연령 총인구다. 따라서 여성만 고르면
‘전체 주민 중 해당 연령 여성 비중’이다. 성별 내부 구성비가 아니다.

전국/시도값은 원자료 공식 합계 행을 사용한다. 지도 연결 지역만 합산한 값을 전국값으로 쓰지 않는다.
결측 코드·0인 분모·없는 면적은 null/자료 없음으로 표시한다. 실제 0명과 구분한다.

원자료는 주민등록인구이며 외국인·유동인구를 포함하지 않는다. 거주불명자(2010-10),
재외국민(2015-01) 포함 시점에 따라 시계열의 통계 모집단이 바뀐다.

## 반드시 유지할 한계 안내

현재 보유 `eupmyeondong-boundaries.json`은 연도별 경계가 아니다. 10자리 행정기관코드가
동일한 행만 지도에 연결한다. **당시 경계 재현, 현재 경계로의 과거 인구 재집계, 경계변동 보정은 하지 않는다.**
코드가 같아도 경계가 변할 수 있으므로 코드 연결은 지리적 동일성 검증이 아니다.
분동·합동·코드 변경 전후를 동일 지역의 순수 인구 증감으로 단정해서는 안 된다.
해당 코드가 없는 시점은 시계열 선을 끊고, 지도에 연결되지 않은 지역은 목록/추이만 제공한다.

밀도는 보유 단순화 경계의 구면 면적(섬 포함, 구멍 제외)으로 계산하는 **참고값**이다.
공식 행정면적이나 과거 연도 경계면적에 근거한 정확한 밀도가 아니다. 화면·내보내기에 표기한다.

2026-08은 3,623개 읍면동 통계 중 3,115개 코드만 보유 경계와 연결된다.
2025-12는 3,620개 중 3,525개, 2008-12는 3,550개 중 2,643개다.
2008-12 원본 읍면동 총합은 49,538,151명으로 공식 전국 49,540,367명보다 2,216명 작다.
영월군 합계와 소속 읍면동 합계에서도 같은 차이가 발견된다. 원인을 확정하거나 값을
임의 배분하지 않고 manifest와 화면에 차이를 남겼다. 나머지 18개 시점은 전국 총합과 일치한다.

## 재생성·검증

```sh
node web/scripts/build-population.mjs --latest=2026-08
node web/scripts/build-kakao.mjs
node --test web/tests/*.test.mjs
```

최신 공표월을 공식 페이지에서 확인한 뒤 `--latest`를 변경한다. 이미 있는 CSV는 재다운로드하지 않는다.
새 시점은 공개 CSV에서 검증한 뒤 추가되며 미래 날짜나 없는 연령을 추정하지 않는다.
다운로드 실패 응답은 CSV로 확정하지 않는다. 기존 치과 통계·경계 파일은 변경하지 않는다.

`population-model.mjs`: 순수 계산 / `population.js`: 필터·통계·시계열·Kakao 어댑터.
`population.html`, `population.css`: 독립 화면. 지도는 `kakao-map.js` SDK 렌더러를 공유한다.
연도 자료 캐시 3개, 지역 시계열 캐시 2개로 제한한다. 전국 시계열은 작은 manifest에서 바로 표시한다.

자동검증: 73,087개 지역·시점 기록의 원본 일치, 기록당 303개 연령/성별 값 합계,
기간·성별·연령 경계값, 0과 결측, 면적 구멍/다중 폴리곤, 381개 분할 시계열 일치,
원본/경계 해시, 치과 데이터 미로딩, 기존 카카오 분석 회귀검증.

실제 브라우저 확인: 2025년 65세 이상 전국 10,840,822명, 사직동 1,969명;
사직동 여성 27–43세 1,347명/전체 주민 8,898명(15.1%)이 원자료와 일치.
과거 코드 결측, 미연결 시도 목록, 빠른 연도 전환, 재생/중지, 지도 확대·선택을 확인했다.
390px iframe에서 가로 넘침 없이 필터와 차트가 표시된다. 실제 휴대폰 테스트는 아니다.
내보내기는 파일 저장 링크와 원문 복사를 함께 제공한다. 앱 브라우저의 다운로드 이벤트
대기는 지원 여부를 확인하지 못해 파일 저장 완료까지 검증했다고 간주하지 않는다.

로컬에서 확인한 결과이며 공개 사이트에 배포하지 않았다.

## SGIS 100m 인구 히트맵 (2026-11-06)

### 1km 연령 자료를 이용한 100m 추정 데이터

2024년 전국 1km 격자 인구(총괄·성연령별)를 SGIS 신청번호 `91289`로 승인받아
`../data/raw/2026-11-06/sgis-age-1km/`에 원본 ZIP과 승인 증빙을 보존했다.
75,070개 1km 관측 셀과 1,088,760개 100m 관측 셀을 연결했으며, 각 100m SHP의
전체 면이 해당 1km SHP 안에 포함되는지 모두 확인했다. 격자 코드의 가로·세로
마지막 숫자를 각각 제거해 부모를 찾으며 코드 한쪽의 접두사만 사용하지 않는다.

`scripts/build_sgis_age_estimates.py`가 공식 코드표의 격자 시트를 읽어 0–4세부터
100세 이상까지 21개 연령의 남녀 합계 추정값을 생성한다. 산식은
`1km 연령 인구 × 해당 100m 총인구 / 같은 1km 안의 100m 총인구 합계`다.
출력은 `../data/processed/sgis-age-100m/`의 압축 CSV 두 개(원래 1km, 추정 100m),
코드표, 검증 manifest, 작은 예시 CSV와 README다. 1km 파일은 남녀 연령 원값도 보존한다.

연령 원자료가 없는 곳은 null/공란으로 유지하며 0명으로 간주하지 않는다. 구간 합계도
하나의 연령 항목이 없으면 완전한 합계로 표시할 수 없다. 하위 100m 가중치 합계가 0인
2,415개 1km 셀(하위 2,853개 셀)은 배분하지 않으며 원래 1km 값과 미배분 합계를 보존한다.
배분 가능한 각 연령의 1km 합계는 소수점 8자리 출력 오차 안에서 유지하지만,
비밀보호 처리로 연령별 추정값 합계와 기존 100m 총인구가 다를 수 있다.
이는 같은 1km 안의 연령 공간 분포를 총인구 분포와 같다고 둔 추정이며 건물별 연령은 아니다.

기본 홈·카카오 호환·실험실 화면의 `인구 히트맵 → 연령`에서 연령별 분포를 선택한다.
선택은 19세 이하·20대·30대·40대·50대·60대·70대 이상의 7개로 제한한다.
기본은 ‘전체’이며 기존 100m 총인구를 표시한다. 7개 연령 구간은 1km 자료로 배분한 추정값이다.
70대 이상에는 100세 이상도 포함한다. 5세 구간·직접 범위 선택은 메뉴에서 제공하지 않는다.
원자료가 없는 구간이 하나라도 포함되면 해당 부모 격자 전체를 선택 구간의 결측으로 처리한다.
결측·0인 가중치를 임의로 0명으로 만들거나 일부 연령만 합산하여 완전한 합계처럼 표시하지 않는다.
범례·접근성 이름·설명문에 추정값임을 표시하며, 확대·이동·진하기·번짐을 그대로 조절한다.
기존 읍면동 주민등록 연령 필터와 구분된다. 로컬 구현이며 공개 배포는 별도다.

`scripts/build_sgis_age_web.py`가 검증한 CSV와 같은 가중치·연령 원값을 30개 이진 파일
`dist/data/sgis-age/`에 보관한다(합계 약 41.4MB, 가장 큰 파일 약 7MB).
`SAG1` 형식의 부모는 분모와 21개 연령값, 하위 셀은 EPSG:5181 네 모서리·부모 인덱스·
원래 총인구다. 좌표는 약 0.1m 정밀도이며 결측은 별도 sentinel로 보존한다.
연령을 처음 선택하면 필요한 지역 파일만 동시 4개로 읽는다. 전국 화면에서는 전체 30개가
필요하다. 작업자 캐시는 이 유한한 전국 카탈로그(약 41.4MB)로 제한되며 연령 전환 때 재사용한다.

`age-heatmap-worker.mjs`가 별도 worker의 OffscreenCanvas에서 원래 100m 면을 채색한다.
모든 확대 수준에서 100m 셀의 면을 그대로 사용한다. 연령별 대량 PNG나 수백 MB의
중복 연령별 도형은 만들지 않는다. 새 범위·이동 요청이 오면 이전 계산을 취소하고,
늦게 끝난 그림은 폐기한다. 반경 인구나 건물별 인구가 아니다.
색상은 64단계로 양자화하며, 기준 강도는 기존 전국 총인구 강도 기준에 해당 연령의
전국 배분 가능 인구 비중을 곱한다. 선택 연령 안에서의 상대 밀집도이며 화면·줌에
따라 기준을 바꾸지 않는다. 서로 다른 연령 선택의 같은 색을 같은 인구수로 해석하면 안 된다.
기존 총인구 레이어는 원래 고정 기준과 PNG 피라미드를 유지한다.

```sh
python3 scripts/build_sgis_age_estimates.py
python3 scripts/build_sgis_age_web.py
python3 -m unittest discover -s tests -p test_sgis_age_estimates.py -v
node web/scripts/build-kakao.mjs
node --test web/tests/*.test.mjs
```

선택 의존성 `geo`의 pyproj·xlrd가 필요하다. 전국 CSV의 모든 추정값, 부모별 연령 합계,
원자료 총인구 보존, 코드·결측·명시적 0, 0인 가중치, ZIP 및 산출물 해시를 검사한다.

### 현재 지도 표시

`인구 분석 → 100m 인구 히트맵`에서 붉은색 히트맵을 표시한다. 독립 주소는
`heatmap.html`이다. 지역·역·주소 검색, 전국 보기, 표시 켜기/끄기, 진하기와 번짐을
조절할 수 있다. 기존 주민등록·주간인구와 시점이나 모집단을 혼합하지 않는다.

메인 치과 지도에서도 도구막대의 `인구 히트맵 2024`로 **치과 점과 같은 지도 위에**
겹쳐 표시한다. `지도 설정 → 100m 인구 히트맵`에서 진하기·번짐을 조절한다.
치과 위치·출처 필터·상세 팝업, 시군구/읍면동 전환, 기존 통계 색칠은 그대로 유지한다.
행정구역 통계·치과 집계나 카카오 우선 좌표를 변경하거나 인구를 치과 기록에 합산하지 않는다.
다른 인구 분석 패널로 전환하면 메인 레이어를 숨기고, 복귀하면 설정과 함께 복원한다.

- 원본: `../data/raw/2026-11-06/sgis/`. 2024년 인구 CSV 30개와 2025년 격자 경계 ZIP 30개.
- `scripts/build_sgis_heatmap.py`가 `GRID_CD`로 실제 SHP 도형과 연결하고 EPSG:5179를
  pyproj로 EPSG:4326으로 변환한다. 원본 SHP의 단일 100m 정사각형과 네 모서리를
  확인하고 모서리 좌표를 약 0.1m 정밀도로 보관한다(10km 집계 셀은 약 1m).
- `to_in_001` 총인구 1,088,760개 격자를 보존한다. 그중 명시적 0명 격자는 127,624개다.
  파일에 없는 격자를 0명으로 만들지 않는다. 모든 인구 격자의 경계 연결을 확인했다.
- 웹 자료: `dist/data/sgis-population/`. 100m 셀은 지역별로 나누어 현재 화면과 주변만
  요청한다. 가까운 화면은 실제 네 모서리로 채색하고, 축소 시 아래 이미지 타일로 전환한다.
  500m·2km·10km 집계 파일은 호환·검증용으로 보관하지만 현 히트맵은 사용하지 않는다.
  전국을 보는데 100m 점 백만 개를 내려받지 않는다. 요청 동시 4개, 캐시 36개로 제한한다.
- 이동 중에도 최대 약 120ms 간격으로 주변 자료를 확인한다. 캐시에 있는 자료는 즉시 쓰고,
  화면보다 넓은 범위를 미리 불러온다. 192px 여유를 둔 히트맵 이미지를 지리 좌표에 고정해
  드래그 중에는 이미지 위치만 갱신한다. 이미지 범위·확대 수준·자료가 바뀔 때만
  픽셀을 다시 계산한다. 진하기는 CSS 투명도로, 번짐은 셀을 채색한 이미지의 CSS blur로
  즉시 적용한다. 일부 요청 실패 시 기존 그림을 유지한다.
- 전국 100m 셀 자료는 약 30.5MB(247개 이진 파일)다. `SGC2` 헤더 16바이트에 이어
  셀당 중심 좌표·인구·네 모서리 상대 좌표를 28바이트로 보관한다. 파일 형식과 정밀도는
  manifest에 기록한다. 전체 선행 로딩은 초기 파싱과 메모리 부담을 늘리므로 기본으로 사용하지 않는다.
- 캔버스 히트맵은 Kakao의 공식 지도 투영으로 셀의 네 모서리를 연결해 **면 전체**를
  인구수에 비례해 채운 뒤 그 표면을 번짐 처리한다. 중심점 원이나 방사형 커널을 사용하지 않는다.
  번짐 0이면 원래 셀 면이 그대로 표시된다. **모든 확대 단계에서 같은 100m 인구의 전국
  99백분위 값을 강도 기준으로 사용한다.** 100m 반경 인구나
  건물별 인구를 계산한 값이 아니며 소수 인구의 통계비밀 보호 처리가 반영되어 있다.
- 넓은 화면은 `dist/data/sgis-heat-tiles/`의 PNG를 현재 화면에 합성한다. 원래 100m 셀을
  동일한 색으로 채운 뒤 RGBA 이미지만 BOX 축소한 피라미드다. 500m·2km 인구를 새로
  합산하거나 줌에 따라 색상 구간을 바꾸지 않는다. 화면의 한 픽셀보다 작은 셀은 개별 식별할 수 없다.
  기본 해상도 20m/이미지 픽셀은 넓은 화면에서만 사용하고, 확대하면 실제 셀 경계를 그린다.
  약 28MB의 PNG 1,726개 중 현재 화면에 필요한 몇 장만 로드한다(이미지 캐시 32개).
- 이미지 투영은 EPSG:5181이며 Kakao의 공개 WCONGNAMUL 예제 좌표와 2.5배 관계를 대조한다.
  `population-heat-layer.mjs`를 독립 화면과 치과 지도에서 공유한다. 동일 Kakao 지도 객체의
  오버레이 패널 아래에 합성하므로 치과 클릭·선택·팝업을 가로막지 않는다.
- 출처는 화면에 표시한다. 완성된 활용 결과물 URL 제출은 공개 배포 후 별도 수행해야 한다.

재생성에는 `pyproject.toml`의 선택 의존성 `geo`(pyproj)가 필요하다.

```sh
python3 scripts/build_sgis_heatmap.py
python3 scripts/build_sgis_heat_tiles.py
node web/scripts/build-kakao.mjs
node --test web/tests/*.test.mjs
```

원본 ZIP의 해시, 전국 셀 수, 명시적 0명 셀 수, 단계별 인구 합계, 지역 파일 경계,
좌표 범위, 지연 로딩·캐시·실패 후 재시도를 자동 검증한다. 원본 ZIP은 웹 배포 폴더에 복사하지 않는다.

## 개원/폐업 → 인구 증감

카카오 페이지의 `개원/폐업 → 지도 지표 → 인구 증감`에서 같은 페이지 안에
`population.html?embed=1&mode=change`를 지연 로딩한다. 인구 분포와 별도 프레임으로
필터·지역 선택을 보존하며, 기존 개원/폐업 지표로 돌아가면 원래 기간 조작부를 복구한다.

- 시작·종료 시점은 각 원자료 스냅샷이다. 기본은 최근 두 완료 연말인 2024-12 → 2025-12.
- 증감 인원 = 종료 인구 − 시작 인구. 증감률 = 증감 인원 / 시작 인구 × 100.
- 동일 연령 구간·성별을 양 시점에 적용한다. 기간별 인구 누적이나 출생 코호트 추적이 아니다.
- 시작이 종료보다 늦어지는 조작은 다른 시점을 같은 시점으로 맞춘다. 동일 시점 비교는 0.
- 한쪽 코드/연령 자료가 없으면 비교 불가(null). 시작 인구가 0이면 증감률만 null.
- 목록은 양 시점 코드의 합집합. 신설·폐지 코드도 남겨 누락을 0명으로 오해하지 않게 한다.
- 지도는 증가 초록, 감소 빨강, 변화 없음 흰색, 비교 불가 회색. 구간은 기간 변경에도 고정.
- JSON에 양 시점, 시작/종료 인구·지역명, 증감 인원·증감률과 경계 미보정 한계를 포함한다.

2024→2025 전국 전체 인구 -99,843명, 65세 이상 여성 +301,779명(+5.29%)을 확인했다.
20개 자동 테스트에서 기존 치과 분석, 두 인구 패널 전환, 공식 데이터 계산을 검증한다.

## 치과 현황 → 주간인구 (공식 조사연도 시계열)

`daytime.html?embed=1`을 별도 지연 로딩한다. 기존 치과 지표의 고정 2020년 주간인구
분모와 구분되는 독립 인구 지표이며, 고정 분모 파일은 이번 작업에서 변경하지 않았다.

- KOSIS 공개 대량자료: 2005 `DT_1T0502`, 2010 `DT_1PA1021`, 2015 `DT_1PA1520`, 2020 `DT_1PA2020`.
- 내려받은 원본 ZIP은 `data/incoming/population/daytime/{year}.zip`에 보존한다.
- 원본 내 CP949 CSV를 `node web/scripts/build-daytime.mjs`로 검증·변환한다.
- 배포 JSON `data/daytime-history.json`에는 원표 링크, 원본 SHA-256, 원 코드·명칭,
  지역·성별·연령별 상주/유입/유출/주간인구 52,416개 관측값을 보존한다.
- 비어 있는 원자료는 null이며 0으로 대체하지 않는다. 2025년 및 중간 연도는 미포함.
- 지역·성별·연령 구간 선택과 네 조사연도 시계열, 주간인구·주간인구지수·순유입·증감을 제공한다.
- 주간인구지수는 선택 연령·성별의 해당 연도 주간인구 / 상주인구 × 100이며, 주민등록인구가 분모가 아니다.
- 원표의 시도 및 상위 시와 하위 구가 공존한다. 지역 목록은 합산하지 않고 공식 상위 행을 직접 사용한다.
- KOSIS 지역코드 체계는 배포 경계 코드와 다르므로 시도+시+구 전체 이름으로 연결한다.
  강원·전북의 도 명칭만 정규화하며 다른 명칭 변경·소속 변경은 자동 연결하지 않는다.
  이름이 같아도 과거 경계가 동일하다는 뜻은 아니다. 예: 창원시 통합 효과가 섞일 수 있다.
- 지도 연결은 252개 보유 경계 중 2005년 211곳, 2010년 246곳, 2015년 251곳, 2020년 247곳.
  부천시의 통합 관측값을 원미·소사·오정구에 배분하지 않는다. 미연결 지역도 목록·추이로 보존한다.
- 2005년 구성항목 산식과 공식 주간인구가 다른 원자료 3행(최대 13명)은 원값을 유지하고 화면에 안내한다.
  2010·2015·2020년 수치가 모두 있는 행은 산식과 일치한다.
- 2005년에는 65세이상/65~69세/70세이상 구간이 함께 있다. 중복 합산하지 않고 원 구간 하나를 선택한다.
  이후 연도에 없는 고령 구간의 시계열은 자료 없음으로 표시한다.

검증: `node --test web/tests/*.test.mjs` (25개 테스트). 모든 원본 셀·해시 대조,
전국 통제값, 결측/0/증감 산식, 지역명 중복, 추정 배분 배제, 기존 직접 발표 2020년 값과 대조.
브라우저: 강남구 2005/2010/2015/2020 주간인구 910,138 / 952,610 / 995,036 / 961,600명,
30~34세 여성 필터, 부천 원미구 2020년 결측, 패널 간 필터 유지 확인.

### 개원/폐업의 주간인구 증감

`개원/폐업 → 주간인구 증감`은 독립된 지연 로딩 패널에서

## 전국 100m 종사자 히트맵 (2026-11-07)

- 홈과 실험실에서 거주인구(선홍색)와 종사자(하늘색과 파란색 사이)를 각각 켜고 끄며 동시에 표시할 수 있다. 기본값은 둘 다 켜짐이다. 연령은 거주인구에만 적용한다. 범례는 두 레이어를 구분해 나란히 표시한다.
- `PopulationHeatLayer`의 같은 셀 폴리곤 렌더러와 래스터 피라미드, 진하기, 지상 거리 기준 번짐을 재사용한다. 두 데이터셋의 캐시는 분리하며 비활성 레이어는 숨긴다. 종사자 셀과 개요 이미지 모두 같은 밝은 파란색 팔레트를 사용한다.
- 종사자는 SGIS 전국사업체조사의 사업체 소재지 기준이다. 통행·방문자 수 또는 특정 시간대 현주인구로 해석하지 않으며 거주인구와 단순 합산하지 않는다.
- 2025년 전국 격자 경계를 재사용한다. 통계 원자료는 별도 신청한 2024년 종사자 100m 격자이다. 비밀보호·미수록 값은 0으로 채우지 않는다.
