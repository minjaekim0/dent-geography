# 심평원–카카오 현재 치과 위치 대조

사용자 요청(2026-11-03)에 따라 동일 기관으로 연결된 경우 카카오 좌표를 우선한다.
원본 SQLite와 기존 통계·과거 사건 지도는 수정하지 않는다.

## 입력과 출력

- DB의 `raw_files`에서 마지막 HIRA 분기 스냅샷 기준일을 찾는다. 개설·폐업 CSV 수집일과 혼동하지 않는다.
- 해당 기준일이 `last_seen`인 영업 치과의원·치과병원을 대상으로 한다. 보유 최신 현황은 2026-06-30, 19,624기관(치과의원 19,376·치과병원 248)이다. 현재 시점의 영업 여부를 보증하지 않는다.
- 결과 위치: `data/processed/kakao-reconciliation/current/`.
- `manifest.json`: 입력 해시·기준일·API·좌표 우선순위.
- `input.json`: 원본 기관키·이름·주소·전화번호·심평원 좌표.
- `responses/`: 요청별 조회일·검색어·공식 응답의 장소 필드. 비밀키는 저장하지 않는다.
- `audit.json`: 기관별 연결 상태·근거·카카오 후보·좌표 차이.
- `review.csv`: 기관명·주소·선택 좌표·출처·좌표 차이·카카오 링크를 엑셀 등에서 검토할 수 있는 표.
- `current-clinics.geojson`: 카카오 우선으로 선택한 현재 위치. 미연결은 심평원 미검증 좌표, 양쪽에 유효한 좌표가 없으면 null geometry다.
- `summary.json`: 상태·좌표 출처별 건수·실제 호출 수·중단 사유·진행 완료 여부.

내부 결과는 웹 공개 폴더 밖에 보관한다. GitHub Pages 공개 사이트에 자동 배포하지 않는다.

## 자동 연결 기준

1. 지역+기관명으로 키워드 검색한다. 검증 대상인 심평원 좌표를 검색 반경의 중심으로 강제하지 않는다.
2. 카카오 치과 분류를 사용하되, 심평원 치과의 이름·건물 주소가 일치하면 카카오의 일반의원 분류도 허용한다. 주차장·기공소·연구소 등은 제외한다.
3. 공백·문장부호·치과의원/치과 표기를 통일하고 지역·상호의 순서, 지점 표기, SM/에스엠 등 영문·한글 발음과 중복 병기를 대조한다. 실제로 다른 지점명과 다른 상호를 단순히 지우거나 글자 순서를 무작위로 바꾸어 연결하지 않는다.
4. 건물 주소가 같은 후보를 우선 연결한다. 건물 주소가 달라도 같은 시군구 내 정규화 기관명이 일치하는 고유한 치과 후보는 카카오 주소·좌표로 연결한다(2026-11-03 사용자 요청). 다른 시군구의 동명 후보는 자동 연결하지 않는다. 지번 주소만 있어도 지역을 확인할 수 있으면 동일 기준을 적용한다.
5. 전화번호 일치는 참고 정보로만 보존하고 연결 조건에는 사용하지 않는다(2026-11-03 사용자 요청).
6. 선택 단계의 후보가 하나여야 한다. 같은 장소 ID가 재사용되면 단일 건물 주소 일치 후보가 있는 경우 해당 기관만 승인하고, 나머지는 보류한다. 건물 주소 일치 후보도 여러 기관에 겹치면 모두 보류한다.
7. 최대 45건의 노출 결과를 확인한다. 검색이 잘려도 이름·건물 주소가 명확히 맞는 고유 후보는 승인하고 검색 제한 사실을 남긴다. 주소가 다르거나 식별 근거가 부족하면 보류한다.
8. 이름·주소 연결에 성공한 경우 심평원 좌표와 100m 이상 차이가 나더라도 사용자 선호에 따라 카카오 좌표를 우선한다. 차이와 `largeDifferenceReview`를 별도로 남긴다.

이는 **자료 간 동일 기관 연결**이며 실제 건물 위치 실측이나 현장검증은 아니다. `physicalLocationVerified`는 false다.
현재 카카오 위치는 과거 개업·폐업 당시 위치의 근거로 사용하지 않는다.
전체 조회 완료(`complete`)와 전국 실제 치과 전수성은 다르며 `nationalCompletenessVerified`는 false다.

## 실행과 재개

프로젝트 `.env`에 `KAKAO_REST_API_KEY`를 설정한다. 브라우저 지도에 쓰는 JavaScript 키와 다르다.
키를 채팅, 공개 코드, 결과 파일에 기록하지 않는다.

```sh
# 네트워크 없이 입력 준비
python3 scripts/reconcile_kakao_locations.py

# 같은 출력 폴더로 다시 실행하면 완료된 검색은 캐시에서 재판정한다.
python3 scripts/reconcile_kakao_locations.py --collect --max-requests 25000 --workers 12 --delay 0.02

python3 -m unittest discover -s tests -p 'test_kakao_locations.py'
```

`--delay`는 전체 작업의 요청 시작 사이 간격이다. `--max-requests`는 한 번 실행의 상한이며, 캐시 재사용은 차감하지 않는다.
인증·권한·쿼터·연결 오류가 나면 새 요청을 멈추고 중간 결과를 남긴다. 페이지 일부만 받은 검색은 완료 캐시로 저장하지 않는다.
입력이 바뀌면 새 `--output` 폴더를 지정해야 한다. 같은 캐시를 재사용하는 실행은 순차적으로 수행한다.
검색 캐시 버전과 연결 판정 버전은 별도다. 판정 규칙을 변경한 뒤 저장 응답으로 재대조할 때 API를 다시 호출할 필요가 없다.

공식 문서: [로컬 검색 API](https://developers.kakao.com/docs/ko/local/dev-guide),
[카카오맵 API와 키 종류](https://developers.kakao.com/docs/ko/kakaomap/common),
[쿼터](https://developers.kakao.com/docs/ko/getting-started/quota),
[서비스 약관](https://developers.kakao.com/terms/ko/site-terms).
API 검색으로 허용되는 서비스 내 이용과 전국 데이터의 장기 저장·재배포 범위를 동일시하지 않는다. 공개 배포 시 적용되는 이용조건을 별도로 확인한다.

## 근거 우선 연결 — 2026-11-03 (v5)

사용자 요청에 따라 충분한 동일기관 근거가 있는데 단일 형식 조건으로 보류하던 규칙을 보완했다.

- SM/에스엠, Dr/닥터, ONE/원, D&D/디앤디와 중복 병기(에이(A), 브이아이피(VIP) 등)를 비교한다. 실제로 같은 발음을 중복한 괄호만 제거하며, 다른 영문 지점 표기는 유지한다.
- 인천 옛 동구↔제물포구, 중구↔제물포구·영종구도 주소 대조에 반영한다. 새 영종구와 제물포구를 서로 동일 지역으로 취급하지 않는다.
