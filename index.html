        폐업 상위 지역

          데이터 안내 · 집계 기준 및 출처

          과목을 선택하면 시군구·읍면동별 전문의 수를 볼 수 있습니다.

          신규개원·폐업은 최근 12개월 시군구별 발생 건수입니다.

          연도 선택은 개업·폐업 지도와 아래 순위에 적용됩니다. 기관·인력 지도는 2026년 6월 기준입니다.

          API 집계 기준을 불러오는 중입니다.

          신규개원은 인허가일, 폐업은 폐업 상태와 폐업일을 기준으로 집계합니다. 날짜·상태가 충돌하거나 종별이 불명확한 기록은 보류합니다. 심평원·서울시 개폐업 건수를 합산하지 않습니다.

          읍면동은 API 기재 주소의 위치를 현재 배포 경계에 배정한 결과입니다. 좌표가 없을 때 이름·종별·주소가 정확히 일치하는 보유 심평원 좌표만 보완합니다. 좌표 충돌·경계 50m 이내·위치 미확인 기록은 읍면동에서 보류하고 전체 건수에는 포함합니다. 지도에 배정된 기록이 없다는 것은 실제 개폐업이 없었다는 뜻이 아닙니다.

          자료: 행정안전부 의원 API · 병원 API · 연도별 지도 집계 내려받기 (JSON)

          분석 대상은 치과의원·일반 치과병원이며, 대학·치과대학 부속 치과병원은 제외합니다. 인구: 행정안전부 주민등록 인구통계 2026년 6월. 기관·인력: 건강보험심사평가원 전국 병의원 및 약국 현황 2026년 6월.
